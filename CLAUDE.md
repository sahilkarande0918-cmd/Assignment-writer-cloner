## Hard rules
- **No AI contributor attribution anywhere**: no `Co-authored-by` trailers, no "generated by" footers, no bot authors. Commit with the repo's configured human identity (`git config user.name/email`); never change or invent it.
- Groq is the only AI provider. No Gemini / Google AI Studio / Supabase / Cloudflare.
- Secrets are server-only (no `NEXT_PUBLIC_` on keys). Never commit `.env*` (except `.env.example`), weights or datasets.
- Groq returns a Zod-validated **operation plan**, never code. Uploaded documents are untrusted data.
- No fake progress, no fake results, no claims of identical handwriting. Unbuilt features are disabled with a visible reason.
- Ponytail (installed plugin) governs code style: smallest correct diff, stdlib/native first, one runnable check per non-trivial logic.

## Architecture (short)
Next.js 16 App Router (`src/app`), client-heavy studio in `src/components/studio`, shared pure logic in `src/lib` (unit-tested). Server route handlers under `src/app/api` (Groq, storage, jobs). Optional Python worker in `workers/handwriting` polls jobs outbound. Details: `docs/ARCHITECTURE.md`.

## Gotchas
- This Next.js version differs from older docs: read `node_modules/next/dist/docs/` before using unfamiliar APIs. `cacheComponents` is on.
- In the Bash tool, heredocs mangle backslashes — write files containing `\` with the Write tool.
